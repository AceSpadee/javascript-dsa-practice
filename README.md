# JavaScript DSA Practice

A collection of data structures and algorithms challenges completed in JavaScript as part of my technical interview preparation.

## Goals

- Improve JavaScript problem-solving skills
- Learn common data structures and algorithms
- Recognize common interview problem patterns
- Practice analyzing time and space complexity
- Improve unit testing skills with Vitest
- Build long-term retention through repeated problems and cumulative stage tests

## Structure

Challenges are organized into stages that gradually increase in difficulty.

Each challenge contains:

- `README.md` — challenge description and requirements
- `solution.js` — my implementation
- `solution.test.js` — Vitest tests for the solution

## Stages

- [ ] Stage 1 — Foundations
- [ ] Stage 2 — Common Interview Patterns
- [ ] Stage 3 — Core Data Structures
- [ ] Stage 4 — Trees & Graph Traversal
- [ ] Stage 5 — Recursion & Backtracking
- [ ] Stage 6 — Greedy & Dynamic Programming
- [ ] Stage 7 — Advanced Interview Patterns

Each stage ends with a cumulative assessment before moving on to the next stage.

Older concepts are intentionally revisited throughout later stages for additional practice and retention.

## Testing

Tests are written using Vitest.

Run the test suite with:

```bash
npm test
```
